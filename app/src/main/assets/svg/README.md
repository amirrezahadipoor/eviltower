# بردارهای بازی

گرافیک بازی با Compose Canvas و مسیرهای برداری ساخته شده است؛ هیچ PNG برای سوژه‌های بازی استفاده نمی‌شود.
این پوشه جای نگهداری SVG های قابل ویرایش است. نام‌گذاری: `tower_<type>_tier_<01..10>.svg` و
`enemy_<family>_variant_<00..08>.svg`. لایه‌ی پارامتریک در رندرر با سطح ۱ تا ۱۰۰ اندازه، هاله،
جزئیات و ذرات را تغییر می‌دهد. آیکون برنامه نیز VectorDrawable است.
