# بسته‌ی انتشار کافه بازار — برج شیطانی

این پوشه همه‌ی چیزهایی است که برای ثبت بازی در **پیشخوان توسعه‌دهندگان کافه بازار**
(`pishkhan.cafebazaar.ir`) لازم است.

> ⚠️ قوانین و ابعاد موردنیاز کافه بازار ممکن است تغییر کند. **پیش از ارسال نهایی**، مقادیر
> این فایل را با صفحه‌ی راهنمای رسمی پیشخوان بازار (بخش «افزودن برنامه» → «تصاویر») مطابقت
> بده. مقادیر زیر بر اساس الزامات رایج پیشخوان بازار در زمان ساخت این نسخه است.

## ۱. هویت برنامه

| مورد | مقدار |
| --- | --- |
| نام فارسی (عنوان فروشگاه) | برج شیطانی |

| Target SDK | ۳۵ (Android 15) |
| فرمت خروجی | APK امضاشده (بازار عمدتاً APK می‌پذیرد؛ پشتیبانی AAB را در زمان ارسال بررسی کن) |

## ۲. فایل‌های این پوشه

| فایل | کاربرد | مشخصات |
| --- | --- | --- |
| `short-description-fa.txt` | توضیح کوتاه | حداکثر ~۸۰ کاراکتر |
| `full-description-fa.txt` | توضیح کامل | متن فارسی، بدون لینک تبلیغاتی |
| `whats-new-fa.txt` | تازه‌های این نسخه | متن فارسی |
| `icon-512.png` | آیکون فروشگاه | ۵۱۲×۵۱۲ PNG |
| `feature-graphic.png` | تصویر سردر/کاور | ۱۰۲۴×۵۰۰ PNG |
| `screenshots/*.png` | تصاویر بازی | ۶ عدد، ۱۰۸۰×۱۹۲۰ (عمودی ۹:۱۶) |
| `content-rating-fa.md` | اطلاعات رده‌بندی سنی و محتوا | برای فرم رده‌بندی پیشخوان |

### مشخصات تصاویر مورد نیاز بازار (خلاصه)

* **آیکون:** ۵۱۲×۵۱۲ پیکسل، PNG، بدون گوشه‌های گرد سفارشی (بازار خودش ماسک می‌زند).
* **اسکرین‌شات:** حداقل ۱ و حداکثر ۱۲ تصویر (پیشنهاد بازار: ۵ تا ۶ تصویر). PNG یا JPEG،
  نسبت عمودی ۹:۱۶ (۱۰۸۰×۱۹۲۰ توصیه می‌شود؛ ضلع کوچک حداقل ۳۲۰ و ضلع بزرگ حداکثر ۳۸۴۰ پیکسل).
* **تصویر سردر (کاور):** ۱۰۲۴×۵۰۰ پیکسل.
* **ویدیو:** اختیاری، از طریق لینک آپارات.

> 🖼️ **درباره‌ی اسکرین‌شات‌ها:** تصاویر داخل `screenshots/` ماک‌آپ‌هایی هستند که با همان
> پالت، فونت و شکل‌های برداری بازی ساخته شده‌اند (`tools/generate_store_assets.py`).
> پیش از ارسال نهایی، آن‌ها را با تصاویر واقعی گرفته‌شده از بازی روی دستگاه جایگزین کن:
> `adb exec-out screencap -p > 01-main-menu.png`

## ۳. سازگاری با کافه بازار (چک‌لیست فنی)

- [x] **بدون وابستگی به Google Play Services** — نه Firebase، نه Play Billing، نه Play Games،
      نه ورود با گوگل. بازی روی دستگاه‌های بدون سرویس‌های گوگل کاملاً کار می‌کند.
- [x] **پرداخت درون‌برنامه‌ای با SDK رسمی بازار (Poolakey)** —
      `com.github.cafebazaar.Poolakey:poolakey:2.2.0` و مجوز
      `com.farsitel.bazaar.permission.PAY_THROUGH_BAZAAR` در مانیفست.
- [x] **تبلیغات:** به‌صورت پیش‌فرض غیرفعال/شبیه‌سازی‌شده است (`MockAdProvider`). هیچ SDK تبلیغاتی
      وابسته به گوگل در پروژه نیست؛ در صورت نیاز می‌توان یک شبکه‌ی ایرانی را پشت `AdProvider` نشاند.
- [x] **به‌روزرسانی:** هیچ API به‌روزرسانی گوگل استفاده نشده است؛ به‌روزرسانی بر عهده‌ی خود
      کافه بازار است (تصمیم مستند در README).
- [x] **آفلاین:** بازی بدون اینترنت کامل اجرا می‌شود؛ مجوز `INTERNET` فقط برای پرداخت/تبلیغ آینده.
- [x] **امضا:** APK نسخه‌ی انتشار با کلید انتشار امضا می‌شود (README → بخش Signing).

## ۴. کلیدهای پرداخت

پیش از ارسال، کلید عمومی RSA برنامه را از پیشخوان بازار بردار و هنگام ساخت به‌صورت متغیر محیطی
بده تا در `BuildConfig.BAZAAR_RSA_KEY` بنشیند:

```bash
export BAZAAR_RSA_KEY="MIIBIjANBgkqhki..."
./gradlew assembleRelease
```

شناسه‌ی محصولات درون‌برنامه‌ای که باید در پیشخوان ساخته شوند:

| شناسه (SKU) | عنوان | نوع |
| --- | --- | --- |
| `gems_small` | کیسه جواهر کوچک (۲۰ جواهر) | مصرف‌شدنی |
| `gems_medium` | کیسه جواهر بزرگ (۶۰ جواهر) | مصرف‌شدنی |
| `gems_large` | صندوق جواهر (۲۰۰ جواهر) | مصرف‌شدنی |
| `remove_ads` | حذف تبلیغات | یک‌بار خرید |
