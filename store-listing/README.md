# بسته‌ی انتشار کافه‌بازار — برج شیطانی

شناسه برنامه: `ir.hadipoor.eviltower`

## فایل‌ها

- `short-description-fa.txt` توضیح کوتاه فارسی
- `full-description-fa.txt` توضیح کامل فارسی
- `whats-new-fa.txt` متن تغییرات
- `content-rating-fa.md` خوداظهاری محتوایی
- `screenshots/` شش تصویر نمونه با نسبت عمودی؛ تا گرفتن اسکرین‌شات از APK نهایی، این‌ها نمونه‌ی برند و UI هستند.
- `icon-512.png` و `feature-graphic.png` خروجی‌های برداری/برندینگ برای پیشخان

## چک انتشار

بر اساس راهنمای منتشرشده‌ی توسعه‌دهندگان بازار، Target SDK کمتر از ۳۲ مجاز نیست و حجم APK نباید
از ۱۵۰ مگابایت بیشتر باشد. پروژه Target SDK 35 دارد و خروجی باید در پیشخان فعلی با فرمت‌های اعلام‌شده
تطبیق داده شود. اندازه‌ها و فرمت نهایی تصویر را پیش از ارسال در پیشخان بازبینی کنید؛ بازار ممکن است
الزامات تصویری را تغییر دهد.

منبع بررسی در زمان ساخت: https://developers.cafebazaar.ir/fa/guidelines/getting-started/practical-principles
و https://developers.cafebazaar.ir/fa/guidelines/developers-panel/overview
