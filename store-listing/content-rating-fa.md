# رده‌بندی سنی و افشای محتوا — برج شیطانی

پیشنهاد برای فرم پیشخوان: **۷+**؛ خشونت فانتزی و کارتونی، بدون خون و جراحت واقع‌گرایانه.

| موضوع | وضعیت | توضیح |
| --- | --- | --- |
| خشونت | دارد، فانتزی | برج‌ها به هیولاهای خیالی تیر/آتش/یخ/رعد می‌زنند و دشمن با burst برداری محو می‌شود. |
| خون و جراحت واقع‌گرایانه | ندارد | خون، بدن واقعی و صحنه‌ی جراحت نمایش داده نمی‌شود. |
| ترس | خفیف | پس‌زمینه‌ی تاریک، مه و برج شیطانی؛ jump scare ندارد. |
| محتوای جنسی | ندارد | — |
| زبان نامناسب | ندارد | متن بازی فارسی و مؤدبانه است. |
| مواد مخدر/الکل/دخانیات | ندارد | — |
| قمار و loot box | ندارد | — |
| خرید درون‌برنامه‌ای | اختیاری | اتصال به پرداخت Bazaar از مسیر Poolakey؛ دفاع اصلی رایگان و بدون پرداخت قابل بازی است. |
| تبلیغات | ندارد در این build | اینترنت برای هسته‌ی بازی لازم نیست. |
| ارتباط کاربر با کاربر | ندارد | بازی تک‌نفره و آفلاین است؛ leaderboard آنلاین ندارد. |
| داده‌ی شخصی | ندارد | رکوردها در DataStore دستگاه ذخیره می‌شوند و login لازم نیست. |

## مجوزها

- `VIBRATE`: بازخورد اختیاری ضربه به هسته.
- `com.farsitel.bazaar.permission.PAY_THROUGH_BAZAAR`: پرداخت اختیاری کافه‌بازار.

پیش از ارسال، متن این فرم را با گزینه‌های روز پیشخوان Bazaar تطبیق دهید.
